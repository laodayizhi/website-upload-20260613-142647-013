# 好看国产剧 纯静态电影网站

本 ZIP 为生成好的纯静态电影网站，可直接上传到任意静态空间使用。

## 生成结果

- 影片数据解析数量：2000 部
- 独立详情页数量：2000 个，文件名为 `movie-1.html` 到 `movie-2000.html`
- 独立分类页数量：12 个
- 播放源数量：20 个 m3u8 地址，详情页按顺序循环绑定
- 封面引用规则：第 N 部影片引用 `./X.jpg`，其中 `X = ((N - 1) % 150) + 1`

## 封面图片

ZIP 内未包含 JPG 图片。请在网站顶级目录手动放入 `1.jpg` 到 `150.jpg`，所有首页、分类页、排行榜页和详情页都会按规则自动引用。
